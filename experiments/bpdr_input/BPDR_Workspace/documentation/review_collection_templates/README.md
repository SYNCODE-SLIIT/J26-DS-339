# Review and collection templates

Use with [the review/collection plan](../Review_and_Collection_Plan_2026-11-01.md).

- `participant_manifest.template.json`: one future participant's consent,
  partition and recording-record requirements. Empty; no participant enrolled.
- `collection_schedule.template.json`:8 placeholder slots x6 tasks =48 planned
  phrase slots. These are not recruited people or collected recordings.
- `independent_review.template.json`: source suitability and blind paired-review
  fields. Empty; no ratings or training approvals.

Copy templates to the institution-approved restricted data store before actual
use. Do not fill these tracked documentation templates with names, consent
records or private audio paths. Store the identity/contact key separately from
pseudonymous audio/ratings. Repository ignore rules are not access control.

Do not change `template_only` or eligibility flags here to simulate progress.
Actual collection needs its own metadata records and completed consent process.
Confirmation roles must be assigned from metadata before audio analysis; they
are not default training sources. A reviewer's opinion cannot replace the
existing numerical, encoded-audio or source-permission checks.
