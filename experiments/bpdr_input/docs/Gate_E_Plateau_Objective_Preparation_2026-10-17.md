## Exact loss definition

Let a be the A/B original masked MAE on S, r the C/D correction-target MAE on P, and o the C/D zero-target MAE on O, each averaged per example first. Then L_anchor = 0.5a + 0.25r + 0.25o. L_counter = 0.5d_P + 0.5d_O, where d measures shifted-minus-original correction against negative injected detuning on P and zero on O. L_total = L_anchor + 0.1 L_smooth, with L_boundary + L_counter added only for BPDR after 100 warm-up updates. All outputs are correction cents.
